# Check Source

Read the official source. Save the reviewed text to a private local file. Run `npm run desk -- check-source <source> --file=<file> --reference=<capture-reference> --by=<operator>`. The first capture establishes a baseline. Later hash differences create a triage item, not a legal conclusion. Keep the capture in the private evidence store. Do not record a successful check if the source failed to load.
